10.1 AI in Medicine

醫學資料具有大量等特性（臨床記錄、影像、體學資料、文獻）。

分類類型主要任務與研究方向
Diagnostic / Predictive AI診斷輔助與風險／結果預測
Imaging AI醫學影像分析與特徵表示學習（Discriminative）
Biomedical NLP醫學文字、文獻理解與生成處理
Genomics / Drug AI基因探索(施工中)
Generative / Agentic AI自動化(施工中)
⚠️ 重要研究原則：生成式 AI 產出的內容不能直接等同於臨床證據或科學證據。
10.2 Biomedical NLP & 知識 RAG

Biomedical NLP 處理包含bioinformatics。以下為文獻知識萃取流水線：

Biomedical Literature ➡️ Tokenization ➡️ Embedding ➡️ Language Model ➡️ NER/Classification ➡️ Knowledge Extraction
🔬 生物醫學命名實體識別 (NER) 範例：
"PB2 E627K mutation affects host adaptation."
➡️ PB2: Protein | E627K: Mutation | Host: Context | Adaptation: Function
🧬 研究知識 (Biomedical RAG)：

Scientific Papers ➡️ Chunking ➡️ Embedding ➡️ Vector DB ➡️ Semantic Retrieval ➡️ LLM ➡️ Research Answer。這能讓研究問題精準獲得文獻佐證。

10.3 Medical Imaging & Vision Transformer 轉用

Vision Transformer (ViT) 的核心概念是把影像切成 Patch，將 Patch 視為類似 Token 的輸入單位：

Image ➡️ Patch Extraction ➡️ Patch Embedding ➡️ Transformer ➡️ Image Embedding
💡 為何這項技術與 RNA 二級結構研究有關？

因為結構可以被轉換為 2D 矩陣／二值影像 (Pairing Matrix)。因此，影像 AI 的「表示學習 (Representation Learning)」可以被完美轉用到結構的特徵提煉上：

RNA Structure ➡️ 2D Matrix / Image ➡️ ViT ➡️ Embedding
